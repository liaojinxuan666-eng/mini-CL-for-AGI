# mini-cl-for-AGI

最小认知架构，阶段 4：持续学习。

## 目标

验证在顺序训练多个任务时，模型是否会灾难性遗忘。

## 任务

GridWorld 隐式动力学（复用阶段 3 的任务定义）。三个不同世界（seed 42、999、2024），依次训练。

**评估方法**：每训完一个世界，在已训过的所有世界上测试单步 acc。

## 结果

**Baseline（无任何 CL 保护）**：

| 训练阶段 | world 0 (42) | world 1 (999) | world 2 (2024) |
|---|---:|---:|---:|
| 训完 world 0 | 0.9369 | — | — |
| 训完 world 1 | 0.9412 | 0.9517 | — |
| 训完 world 2 | 0.9400 | 0.9487 | 0.9554 |

**没有观察到灾难性遗忘。** world 0 的 acc 从 0.937 → 0.941 → 0.940，基本不变。

## 结论

**当前架构天然抗遗忘。** 原因不是 EWC 或 Replay，而是模型从未把”世界特定规则“存进权重：

- 阶段 3 已经发现：模型在全新世界上的单步 acc = 0.92
- 这说明它学的是”**从当前上下文推断局部动力学**“，而不是”**记住每张地图**“
- 这个推理能力跨世界通用，所以顺序训多个世界不会互相干扰

**含义**：
- 阶段 1-3 的架构设计（SSM + 局部上下文推断）本身就对任务切换鲁棒
- 灾难性遗忘发生在”模型必须把任务特定信息写进权重“的场景，当前任务不满足这个条件
- 因此 EWC / Replay 这类方法在当前任务上没有对照价值

**下一步**：进入阶段 5，内在动机 + 元认知。当前架构已经具备：
- 感知主干 ✅
- 外挂记忆 ✅
- 内部模拟器 ✅
- 跨任务稳定性 ✅

缺的是”**知道自己不知道**“的能力——即用预测误差驱动探索。这正是阶段 5 的核心。
